# 对特定 ZXing reader 采用显式依赖契约

2026-10-17，定向只读调查确认真实插件将全局能力经本地桥交给实际 ZXing Wasm 资源，既有标准宿主及 Node 模块假设不足以证明其非干扰；用户明确批准特定依赖契约与显式证据接口，作为 ADR 0002 的有限补充。对独立批准并绑定资源身份的该组件，信任其在经结构验证的加载、初始化和图像解码全生命周期不修改相关宿主能力、原型、站点状态链绑定及配置，也不安装此类延迟效果；这是接受的语义假设，调查没有证明该性质，不能泛化为任意 Wasm、回调或生成代码的信任。

分析仍须证明资源来源、有限加载器/导入桥/调用点、初始化参数及回调和 hooks 缺失，保留其余相关逃逸、别名、反射和原型修改检查；资源摘要绑定批准及变更检测，不替代结构兼容性。纯源码分析通过显式依赖证据输入保持无隐式 I/O，CLI 只读解析并核对资源，方案绑定契约和依赖证据并重新推导；无证据、未知资源、fallback、额外回调或相关结构变化均拒绝。具体范围见 `docs/design/zxing-dependency-boundary-proposal.md` 及规格增补；不授权真实 bundle/Wasm 执行、安装写入或宿主运行验证。
