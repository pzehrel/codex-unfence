# 以限定版本的实际验证收敛插件适配

2026-10-18，用户接受调整交付目标：在其确认的 Codex 桌面版本上，使仅因 `feature_status.agent === true` 被阻止的浏览器访问能够继续，取得实际生效及可撤销的证据，同时保留用户拒绝、企业策略和其他权限限制。技术方案由可行性证据决定，尚未选定源码补丁或运行时拦截。

此前完整静态证明的实现持续扩大而真实适配未打通。用户接受以限定已确认版本、定向代码审查、关键回归测试和真实运行实验建立交付证据，不再要求完整静态证明；接受可能遗漏副作用及更新后重新验证的代价，不承诺任意版本兼容。这调整 ADR 0001 的生产准入方向及 ADR 0002–0004 对本次后续交付的证明要求，但不追溯宣称既有条件已经证明，也不直接放宽现有分析器、方案验证或应用门禁。原实现与检查点保留；新方案确定后另行更新实现规格。

当前仅授权最多 30 分钟的只读入口调查，确认目标请求的发起位置和用户可控制的拦截入口。期限结束须给出入口及证据，或明确阻断；未找到时停止，不自动延长或开发包装器。原固定样本缺失或身份变化仍须报告，不能自动选择其他版本作为已确认样本。此次接受不授权启动、重启或终止 Codex、连接调试接口、加载自定义代码、实施拦截、修改安装/代理/证书或公共发布；真实运行实验及具体修改范围须在后续明确。

研究依据见 [运行时拦截可行性研究](../../reports/runtime-site-status-interception.zh-CN.md)。本决定取代原规格对后续交付必须完成完整静态证明的要求；原规格和已有测试仍作为此前实现范围与证据记录，不代表新路线已经完成。

原版本材料缺失，首次入口调查提前停止后，用户于 2026-10-18 明确接受将缓存插件 `26.1013.40934` 作为新的只读研究对象，授权读取对应 service、client 和启动 manifest，先记录文件身份，再定向追踪加载者、runtime 创建者及 fetch 实现，最多 30 分钟。该插件与当前桌面应用的对应关系仍须核实；此确认不是原版本验收通过，也不授权真实宿主操作、注入或安装修改。调查结果另行记录，不覆盖原版本的历史身份和失败验收记录。

用户随后接受只读调查桌面宿主，并通过精确目录授权允许访问 `/Applications/ChatGPT.app`。调查确认应用为 `26.1013.40934 / build 20770`，分发插件与缓存对应，但活跃服务分支及可用拦截入口仍未证明，见 [宿主调查](../../reports/host-runtime-entry-investigation.zh-CN.md)。

用户另行接受一次最多 30 分钟的隔离诊断实验：只运行该应用捆绑的 `node_repl` 辅助进程，以临时配置和自写诊断服务检查服务加载机制、服务上下文 `nodeRepl.fetch` 的可见性、可写性和初始化时机。不启动桌面应用、不加载真实浏览器服务、不调用 fetch 发出业务请求、不改目标字段或安装文件；需要现有账号状态或超出隔离范围时停止。此授权有限放开辅助进程执行，不授权其他真实模块执行、真实宿主注入或流量改写；隔离结果不能直接作为真实 Codex 生效证据。

隔离诊断已完成，见 [诊断报告](../../reports/isolated-node-repl-diagnostic.zh-CN.md)：自写服务开始执行时 nodeRepl 已冻结，fetch 不可写、不可配置，普通用户上下文没有该 fetch。因此停止普通用户 JavaScript 直接修改服务 fetch 的路线，不将实验结果扩大成真实宿主验收或所有运行时方案均不可行。用户随后接受最多 15 分钟只读核对决定浏览器服务分支的配置，并授予 `/Users/pzehrel/.codex` 目录访问；仅检查相关选择字段，不读取对话、凭证或启动/重启应用。配置不足确认实际加载分支时报告未知并停止，不自动扩大读取范围。

用户随后明确：所需方案是通过补丁在插件内部的请求／响应通道注入包装器，保留原请求与判定器，仅改写目标响应解析后的字段；不是 HTTPS 中间代理，也不是把判定结果归 false。定向核对定位了 CUA 专用运输函数后，用户调用 `/implement` 授权实现本地副本及关键行为测试、独立审查和本地提交；不写入安装、不执行真实插件。具体交付契约见 [本地副本切片](../design/cua-request-wrapper-slice.md)。该路线不依赖冻结宿主属性可写，不恢复完整静态证明工程，也不把本地副本成功声称为真实运行生效。
