# 将结构准入收敛到局部注入契约

2026-10-22，用户在验证新版 Codex 后确认：插件文件补丁只替换一个 fetch await 表达式，结构兼容性不应继续要求整个请求构造、策略类、缓存、初始化和最终拦截链符合历史模板。新准入识别站点状态端点的局部来源、唯一注入点，以及响应只使用现有包装器提供的 `ok` 和无参数 awaited `json()`；解析结果需进入 `feature_status` 消费，原请求接收者、参数、求值次数及范围外代码保持。

此决定收缩 ADR 0005 的有限模式范围，接受宿主标准接口和外围代码不干扰选定通道的假设；结构支持仅表示能够生成满足局部契约的补丁，不代表当前宿主加载或站点行为已经验证。候选歧义、运输函数混用于其他通道、响应逃逸或额外接口使用仍拒绝；新增请求属性和缓存变化本身不再阻止准入。

既有恢复记录绑定完整历史 evidence 和 assumptions，改变文案也会使其失效。因此保留历史分析器，仅在加载匹配历史 basis 的记录时重算并核验原 manifest、补丁字节和差异；新准入独立使用局部分析器，不能通过历史分析器放行。此次保留既有响应包装字节及恢复格式，后续若调整包装行为，应另行定义配方兼容策略。
