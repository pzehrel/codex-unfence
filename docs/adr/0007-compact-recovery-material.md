# 以完整原文件和简短记录恢复单文件补丁

2026-10-27，用户确认单文件补丁的恢复材料应精简：新准备仅保存安装前完整文件及包含目标、应用与工具版本、原始和补丁摘要、小段替换内容的元数据；补丁全文可由保存的替换内容重建，操作记录引用同一份备份，重复安装和卸载不新增事务。保留原子替换、并发锁、操作阶段记录及中断回滚，避免为节省材料而依赖不可靠的反向源码定位；历史材料保留读取与校验，不自动重写或删除。

恢复按已认证的材料、字节摘要和文件身份判断，不再要求重新生成完整历史 evidence、assumptions 或相同分析文案，调整 ADR 0006 中重算历史分析依据的要求；当前分析器只决定新安装是否结构兼容，失去结构支持不应取消已有有效备份的恢复能力。备份缺失、记录不完整或目标存在未知修改仍须明确报告并停止自动覆盖；缺少旧恢复材料时，结构分析结果仍独立展示，不能用恢复错误代替兼容性结论。

用户同时确认相关应用及服务仍运行只产生警告，不阻止安装、卸载或回滚；写入后必须完整退出应用和相关服务再重新启动，运行生效仍单独验证。进程枚举仍用于并发锁身份判断，枚举失败不等同于发现活跃应用，继续阻止写入。
