## 行为

在专用运输函数成功收到原 fetch 响应后，返回仅面向当前消费者的自有 `ok/json` 适配对象。原 fetch 参数、调用接收者、次数、类型检查及等待保持原样；原判定器、调用参数、缓存、inflight、HTTP 检查和异常处理保持源码不变。`ok` 在消费者读取时转发原 response.ok；`json()` 保持原 response 接收者调用原解析方法，每次仅调用一次并等待结果，不捕获或转换原错误。

只在正常 JSON 对象及其 feature_status 对象的 agent 字段严格为 true 时创建浅副本，把 agent 改为 false；其余 JSON 字段保留、原对象不变。缺失字段、false、非布尔值、null、数组及不支持形态原样返回。实现必须清楚限定对象形态，不声称任意 Proxy、accessor 或标准 Response 全接口透明。当前唯一消费者只读 ok 并 await json；若接口或消费者变化，应拒绝原配方。
